# Overview

When you added an IP or URL into Netskope URL List you do not remember why and when you did it.
The Netskope List Management SP is a set of playbooks to manage the content of Netskope URL list by using the Threat Intelligence FortiSOAR Application as object repository.
Each entry in TIM is created with the "valid until" value based on the duration value defined in the Configuration step.
